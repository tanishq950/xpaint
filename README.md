# CG Paint Studio

A basic MS Paint-like Computer Graphics project made with HTML5 Canvas, CSS, and JavaScript.

## Features

- Freehand pencil and eraser
- Line, rectangle, circle, and triangle shapes
- Optional shape fill
- Text insertion
- Color picker and preset colors
- Brush size control
- Undo and redo
- Clear canvas
- Save drawing as PNG

## How to run

Open `index.html` in any modern web browser. No installation or internet connection is required.

## Keyboard shortcuts

`P` Pencil, `L` Line, `R` Rectangle, `C` Circle, `T` Triangle, `X` Text, `E` Eraser, `Ctrl + Z` Undo, `Ctrl + Y` Redo.
